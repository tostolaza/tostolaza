### Sobre mí

Profesional de ciberseguridad con experiencia en pruebas de penetración, análisis de vulnerabilidades y desarrollo de herramientas de seguridad. Trabajo en evaluaciones de seguridad web e infraestructura, participo en programas de bug bounty, y desarrollo automatización de pentesting con IA.

Cuando no estoy rompiendo cosas, las construyo: programación a bajo nivel en C, hardware hacking con ESP32, y herramientas de seguridad en Python y Bash.
